Projeto 1 · Python + SQL · mineração

Para onde vão os royalties da mineração? Análise da CFEM

Quais substâncias, estados e municípios concentram a arrecadação da CFEM, e como ela varia ao longo do ano?

A CFEM é a compensação financeira paga pelas mineradoras sobre o faturamento. A base usada aqui é simulada, com o mesmo layout dos dados abertos da ANM (2019 a set/2025), e inclui de propósito os problemas reais desse tipo de arquivo. Os valores servem para demonstrar o método, não são números oficiais.

1 · Limpeza em Python

Leitura do CSV no padrão brasileiro (ponto e vírgula, vírgula decimal, cp1252), padronização de nomes e de grafias, remoção de duplicadas.

2 · Carga em SQLite

Tabela única com data mensal e uma flag para registros sem quantidade, sem descartar o valor recolhido.

3 · Perguntas em SQL

CTEs e window functions: variação anual com LAG, Pareto com soma acumulada, ranking por estado com RANK e média móvel de 3 meses.

O que os dados mostram
  • Minério de ferro responde por 87,9% da arrecadação. Com o cobre, chega a 94,4%. Qualquer variação no preço do ferro mexe com quase toda a receita.
  • O Pará concentra 71,7% do total, e só Parauapebas e Canaã dos Carajás somam 66,6%. A dependência de poucos municípios é o principal risco para quem planeja essa receita.
  • A arrecadação teve pico em 2021 (+46,6% sobre 2020) e caiu 26% até 2024, o que acompanha o ciclo de preço do minério.
  • Janeiro e fevereiro são os meses mais fracos. De julho a setembro a média é cerca de 39% maior, um padrão útil para projeção de caixa dos municípios.

-- Q1. Quanto se arrecadou por ano e qual foi a variação em relação ao ano anterior?
WITH anual AS (
  SELECT ano, SUM(valor_recolhido) AS total
  FROM cfem
  WHERE ano < 2025                      -- 2025 vai só até setembro
  GROUP BY ano
)
SELECT ano,
       ROUND(total / 1e6, 1) AS total_milhoes,
       ROUND(100.0 * (total - LAG(total) OVER (ORDER BY ano))
             / LAG(total) OVER (ORDER BY ano), 1) AS variacao_pct
FROM anual
ORDER BY ano;

-- Q2. Quais substâncias concentram a arrecadação? (participação e acumulado, estilo Pareto)
WITH por_subst AS (
  SELECT substancia, SUM(valor_recolhido) AS total
  FROM cfem GROUP BY substancia
)
SELECT substancia,
       ROUND(total / 1e6, 1) AS total_milhoes,
       ROUND(100.0 * total / SUM(total) OVER (), 1) AS part_pct,
       ROUND(100.0 * SUM(total) OVER (ORDER BY total DESC)
             / SUM(total) OVER (), 1) AS acumulado_pct
FROM por_subst
ORDER BY total DESC;

-- Q3. Top 3 municípios arrecadadores em cada estado
WITH mun AS (
  SELECT uf, municipio, SUM(valor_recolhido) AS total
  FROM cfem GROUP BY uf, municipio
), ranqueado AS (
  SELECT *, RANK() OVER (PARTITION BY uf ORDER BY total DESC) AS posicao
  FROM mun
)
SELECT uf, posicao, municipio, ROUND(total / 1e6, 1) AS total_milhoes
FROM ranqueado
WHERE posicao <= 3
ORDER BY uf, posicao;
"""Projeto 1 - CFEM: limpeza e padronização da base de arrecadação.
Entrada: CFEM_Arrecadacao_simulada.csv (layout da ANM, ';' e decimal ',', cp1252)
Saída: cfem_limpo.csv + cfem.db (SQLite para as consultas em SQL)
"""
import sqlite3, unicodedata
import pandas as pd

ENTRADA = "CFEM_Arrecadacao_simulada.csv"
df = pd.read_csv(ENTRADA, sep=";", decimal=",", encoding="cp1252")
log = {"linhas_brutas": len(df)}

# 1. Nomes de colunas sem acento, em snake_case
def sem_acento(s):
    return unicodedata.normalize("NFKD", s).encode("ascii", "ignore").decode()
df.columns = [sem_acento(c).lower() for c in df.columns]
df = df.rename(columns={"tipo_pf_pj": "tipo_pessoa", "cpf_cnpj": "documento",
                        "anodoprocesso": "ano_processo",
                        "quantidadecomercializada": "quantidade",
                        "unidadedemedida": "unidade", "valorrecolhido": "valor_recolhido"})

# 2. Padronizar substância: espaços, caixa e acentos ("Minério de Ferro", " MINERIO DE FERRO")
mapa = {"MINERIO DE FERRO": "MINÉRIO DE FERRO", "AGUA MINERAL": "ÁGUA MINERAL",
        "NIOBIO": "NIÓBIO", "NIQUEL": "NÍQUEL"}
original = df["substancia"].copy()
chave = original.str.strip().str.upper().map(sem_acento)
df["substancia"] = chave.map(mapa).fillna(original.str.strip().str.upper())
log["grafias_corrigidas"] = int((original != df["substancia"]).sum())

# 3. Remover linhas duplicadas
dup = df.duplicated().sum()
df = df.drop_duplicates()
log["duplicadas_removidas"] = int(dup)

# 4. Quantidade vazia: manter a linha (o valor recolhido existe), marcar com flag
df["quantidade_informada"] = df["quantidade"].notna()
log["quantidades_vazias"] = int((~df["quantidade_informada"]).sum())

# 5. Coluna de data para séries mensais
df["data"] = pd.to_datetime(dict(year=df["ano"], month=df["mes"], day=1))

df.to_csv("cfem_limpo.csv", index=False, encoding="utf-8")
with sqlite3.connect("cfem.db") as con:
    df.assign(data=df["data"].dt.strftime("%Y-%m-%d")).to_sql("cfem", con, if_exists="replace", index=False)

log["linhas_finais"] = len(df)
log["substancias_distintas"] = df["substancia"].nunique()
print(log)
